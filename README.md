# Sistema de Projetos e Portfólio

Projeto acadêmico desenvolvido durante as aulas do curso de Análise e Desenvolvimento de Sistemas da FATEC, com base nos materiais e códigos fornecidos pelo professor.

O objetivo do projeto é colocar em prática conceitos de programação Java, orientação a objetos, persistência de dados, desenvolvimento de APIs REST e integração entre aplicações desktop e web.

## Tecnologias utilizadas

- Java 21
- Maven
- Javalin
- Java Swing
- HTML, CSS e JavaScript
- CSV
- HTTP e JSON

## Funcionalidades

- Cadastro e listagem de projetos
- Busca por ID, categoria e status
- Alteração e exclusão de projetos
- Armazenamento dos dados em arquivo CSV
- Interface gráfica desktop com Swing
- API REST com operações CRUD
- Interface web integrada à API

## Estrutura do projeto

- `model` — Classes que representam os dados
- `service` — Regras de negócio
- `dao` — Leitura e gravação de arquivos CSV
- `api` — API REST desenvolvida com Javalin
- `view` — Interface desktop com Swing
- `web` — Interface web com HTML, CSS e JavaScript
- `dados` — Arquivo CSV utilizado para armazenar os projetos

## Objetivo acadêmico

O sistema foi utilizado como atividade prática para acompanhar a evolução de uma aplicação Java, desde a criação de classes e objetos até a integração entre frontend, backend e persistência de dados.

**Observação:** Projeto desenvolvido com finalidade educacional, seguindo as orientações e os materiais disponibilizados pelo professor durante as aulas.
